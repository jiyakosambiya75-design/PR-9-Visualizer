## 🛑 Critical System Quirks & Operational Anomalies
When working within this specific script layout, keep these native terminal constraints and design quirks in mind:

   1. Menu 6 Index Trapping Loop: Inside the choice validation block for option 6 (Data Visualization), a secondary internal choice duplicates an index check structural space before hitting the main menu escape sequence. This means typing certain options generates a plot but will not break back out to the main menu directly without explicitly selecting the final menu exit step. 🔄
   2. Imputation Data Type Forcing: Selecting missing data replacement protocols processes input arguments as direct text strings. If you enter alphanumeric strings into a strictly numeric column, downstream analysis modules (like numeric calculations or plotting metrics) can run into unexpected system runtime exceptions. Always make sure your replacement values match the target data type! 🔤

To get the cleanest insights and avoid running into unhandled structural faults, keep these professional data preparation tips in mind:
